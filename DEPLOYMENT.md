# Deployment Note

This project was created as a study and learning project for Next.js, Prisma, Supabase, and AI-assisted note workflows.

It is not intended for production deployment or public hosting as-is. If you want to run it locally for experimentation, set up your own local environment variables and database connection and keep them out of version control.

## Local study usage

- Use a local PostgreSQL instance or a private dev database.
- Store environment values in a local `.env.local` file.
- Do not commit secrets to GitHub.
- Keep this repository private if you are testing any real credentials.

## General stack used

- Next.js
- Prisma
- PostgreSQL
- Supabase Auth
- OpenAI API

## Important note

This repository is meant for code exploration and learning rather than for public-facing deployment.
